# Pawmodoro 🐾 — Plan: Cozy Pomodoro App for iOS

A cutesy, cozy Pomodoro timer where a cat or dog buddy keeps you company.
Your buddy naps while you focus ("don't wake the kitty!") and plays during
breaks. Warm pastel palette, rounded shapes, soft animations — the vibe of
cozy pixel-art games.

## Concept

- **Name:** Pawmodoro
- **Hook:** Focus sessions earn paw prints; your buddy reacts to your progress
- **Audience:** Students, remote workers, cozy-game fans

## Phases

### Phase 1 — MVP ✅
- [x] Classic Pomodoro: 25 min focus / 5 min short break / 15 min long break (all adjustable)
- [x] Auto-cycling phases with a paw-print cycle counter (long break every 4 focus sessions)
- [x] Cat or dog buddy with mood states (napping while you focus, playing on breaks)
- [x] Local notification when a timer ends (works even if app is backgrounded)
- [x] Haptic feedback on phase changes
- [x] Settings: durations, buddy choice, sessions per long break, haptics
- [x] Timer survives backgrounding correctly (computes from end date, not ticks)

### Phase 2 — Polish ✅
- [x] App icon — 1024×1024, generated by `tools/generate_assets.py`
- [x] Ambient sounds — Rain / Purr / Fireplace loops, synthesized so there's nothing to license
- [x] Phase-end chime
- [x] Stats screen — today, last 7 days, current + best streak, 7-day bar chart
- [x] Onboarding — three pages: welcome, how the loop works, pick your buddy
- [x] Auto-start next phase option
- [x] Accessibility labels on all controls
- [x] **Real buddy art** — pixel-art sprites (awake + asleep, cat + dog) generated by
      `tools/generate_sprites.py`. Original artwork, nothing to license, and no art budget
      needed. Emoji remain as a runtime fallback. Commissioning hand-drawn sprites later is
      now an optional upgrade rather than a blocker.
- [x] **Dark mode** — the whole palette adapts to system appearance (cozy plum night theme)
- [x] **Contrast fix** — white on the pastel accents measured as low as 1.5:1, far below the
      4.5:1 minimum. Replaced with `Theme.onAccent`, a soft cocoa clearing 5.5:1 everywhere.
- [x] Respects Reduce Motion
- [ ] Live Activity on lock screen / Dynamic Island — code and step-by-step instructions are
      ready in [`LIVE_ACTIVITY.md`](LIVE_ACTIVITY.md). It needs a Widget Extension target,
      which Xcode must create; do this once the app builds cleanly on your Mac.

### Phase 3 — Launch (~1 week)
- [ ] Build and run on a real iPhone (see `docs/XCODE_WORKFLOW.md`)
- [ ] Follow `docs/APP_STORE_LAUNCH_GUIDE.md` step by step
- [ ] Enroll in the Apple Developer Program ($99/yr, 1–2 days to approve)
- [ ] Replace the placeholder bundle ID `com.example.pawmodoro` with your own
- [ ] TestFlight beta with a few friends first
- [ ] Screenshots (⌘S in the simulator, then AppMockUp for captions/frames)
- [ ] Publish a privacy policy page (GitHub Pages is fine — the app collects nothing)
- [ ] Submit for review

### Phase 4 — Post-launch ideas
- [ ] More buddies (bunny, hamster) — new sprites are ~20 lines in `tools/generate_sprites.py`;
      possible cosmetic in-app purchase
- [ ] Buddy levels up / unlocks accessories with completed sessions
- [ ] Home screen widget showing today's paw prints (reuses the Widget Extension from
      the Live Activity work)
- [ ] Apple Watch companion
- [ ] More ambience: café, forest, lo-fi (real recordings once there's a budget)
- [ ] Hand-drawn or animated buddy sprites to replace the generated ones

## Monetization (decide before Phase 3)
- **Free** — simplest first launch; build reviews and downloads
- **Free + one-time "tip jar" or cosmetic IAP** — good fit for the cozy audience
- Avoid subscriptions for v1; not worth the extra review scrutiny and setup

## Tech decisions
- **SwiftUI**, iOS 17+, zero third-party dependencies
- **Observation** (`@Observable`) rather than `ObservableObject` — the current idiom on iOS 17
- Settings live in one `Codable` struct with lenient decoding, so adding a field later
  never wipes a user's existing preferences
- Timer stores an absolute end `Date` and reschedules notifications — the only correct
  approach on iOS, since apps get suspended in the background
- Audio uses the `.ambient` session category, deliberately avoiding the background-audio
  capability that App Review scrutinises
- Emoji buddy art as a placeholder so the app is fully functional before any art spend
